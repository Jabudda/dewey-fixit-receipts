# Dewey Fixit receipts

Sources for every fact in the Dewey Fixit / The Smuchgum Files Shorts on YouTube ([@Dewey_Fixit](https://www.youtube.com/@Dewey_Fixit)), one row per episode, newest first.

Live page: https://jabudda.github.io/dewey-fixit-receipts/

The page is a single `index.html` with no build step. Each new episode adds one `<li class="ep">` row at the top of the list.
